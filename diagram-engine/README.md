# diagram-engine (Faz 2+ — henuz uygulanmadi)

Bu klasor, "Diagram Design" (Cathryn Lavery) yaklasimindan ilham alan,
generic Mermaid ciktilarini atlayip auto-styled, editoryal kalitede SVG/HTML
diyagramlar ureten Claude Code skill wrapper'ini barindiracak. Girdi olarak
`.memory/graph-map.json`'i kullanacak.

**Faz 1 kapsaminda buraya kod YAZILMADI.** Bu dosya sadece yapisal bir
placeholder'dir; kullanicinin "GO" onayi sonrasi ilerleyen fazlarda
doldurulacaktir.
